ALICE IN BORDERLAND — 52-CARD GAME COLLECTION

PROJECT FILES
- index.html: main collection landing page and integrated King of Diamonds, Queen of Diamonds, and Queen of Hearts games.
- Two_of_Hearts.html: standalone game document loaded by the 2♥ card (The Mirror Pulse).
- Three_of_Hearts.html: standalone game document loaded by the 3♥ card (The Glass Collar).
- King_of_Hearts.html: standalone game document loaded by the K♥ card (The Panopticon Banquet).

IMPORTANT: Keep all four HTML files in the same folder. The main index.html loads the three new Hearts games in a full-screen embedded frame. Each Hearts game file can also be opened directly on its own.

PLAYABLE CARDS
1. KING OF DIAMONDS (K♦) — BEAUTY CONTEST
   Five players, a 0–100 number choice, an 0.8×mean target, points and eliminations, with the later-stage rules described in the game.
2. QUEEN OF DIAMONDS (Q♦) — THE PARADOX AUCTION
   Five players, sealed bids, predictions about other players' bids, local strategic AI, staged auction modifiers, scoring and elimination.
3. QUEEN OF HEARTS (Q♥) — TEA AT THE EDGE
   Three-cup Monte, psychological dialogue, shifting round counter, false exit/crash trap, synthesized audio, and psychological telemetry.
4. TWO OF HEARTS (2♥) — THE MIRROR PULSE
   A five-stop sealed subway transit game. Manage gas-mask filters, decide whether to mask, assess the chemical sensor and Noa's intercom clues, and optionally pass a filter through the bulkhead.
5. THREE OF HEARTS (3♥) — THE GLASS COLLAR
   Four participants in an optical courtyard. Wolf status transfers through line of sight; hiding and radio commitments affect tactical options and AI trust. Survive six pulses or trigger the optical-array overload condition.
6. KING OF HEARTS (K♥) — THE PANOPTICON BANQUET
   A ten-guest survival/strategy game with eight citizens (you plus seven AI) facing two hidden Sovereigns, daily vitality decay, rationing, solidarity, gifts, a public ledger, whispers, and a purge objective.

CARD APPEARANCE
- All playable cards receive the existing gold PLAY treatment.
- Suit symbols on playable cards (center and corner symbols) are gold; rank lettering keeps its standard red/black coloring.
- The original 52-card landing-page layout and visual template are preserved.

HOW TO PLAY
1. Open index.html in a modern browser.
2. Select a playable card. The three newly added Hearts games open inside the collection's full-screen game viewer.
3. Use “Back to Deck” in the viewer toolbar to return to the 52-card collection. Pressing Escape also closes the viewer.
4. The other 46 cards remain unavailable placeholders.

The project uses no app build step or API keys. The supplied game files use Tailwind CSS and Google Fonts CDNs, so those visual resources require an internet connection; the game logic itself is client-side.

GITHUB PAGES HOSTING
1. Upload index.html, Two_of_Hearts.html, Three_of_Hearts.html, King_of_Hearts.html, and optionally README.txt to the same repository folder (usually the repository root).
2. Enable GitHub Pages from Settings > Pages, deploying the main branch and root folder.
3. Open the published Pages URL.
